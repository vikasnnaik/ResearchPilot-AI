# ResearchPilot AI – Advanced Autonomous Multi-Agent Research System

> **Global AI Hackathon 2026** | Tavily Research Agent Track

ResearchPilot AI is an advanced, autonomous multi-agent research intelligence platform designed to eliminate synthetic hallucinations and deliver verifiable, publication-ready research reports. Powered by **LangGraph** with dynamic conditional looping and **Tavily Web Search**, ResearchPilot decomposes complex queries, queries the live internet across multiple autonomous iterations, identifies information gaps, extracts verbatim evidence quotes, audits empirical contradictions, and compiles executive PDF dossiers.

---

## 🏗️ Architecture & Autonomous Multi-Agent Workflow

```
                                  +-------------------+
                                  |    User Query     |
                                  +---------+---------+
                                            |
                                            v
+-----------------------------------------------------------------------------------------+
| LangGraph Autonomous Iterative StateGraph                                               |
|                                                                                         |
|  [Planner Agent]      Deconstructs topic into 4–6 targeted search questions             |
|         |                                                                               |
|         v                                                                               |
|  +-> [Research Agent] Queries Tavily Search API, normalizes, deduplicates URLs,         |
|  |      |             and assesses epistemic source quality (primary/secondary)        |
|  |      v                                                                               |
|  |   [Analysis Agent] Synthesizes categorized factual findings bound to source URLs     |
|  |      |                                                                               |
|  |      v                                                                               |
|  |   [Gap Evaluator]  Audits information completeness & formulates follow-up queries    |
|  |      |                                                                               |

|         |                                                                               |
|         v (When evidence is saturated or max 3 loops reached)                           |

|         |             detects contextual contradictions; calculates quality metrics     |
|         v                                                                               |
|      [Report Agent]   Synthesizes comprehensive executive dossier & citations           |
+-----------------------------------------------------------------------------------------+
                                            |
                                            v
                        +---------------------------------------+
                        | Interactive Dashboard & PDF Export    |
                        +---------------------------------------+
```

### The Autonomous Multi-Agent Nodes

1. **Planner Agent (`backend/agents/planner.py`)**  
   Synthesizes the core strategic objective and generates 4 to 6 focused, non-overlapping research questions with domain categorization and rationale.

2. **Research Agent (`backend/agents/researcher.py`)**  
   Executes live search queries via the Tavily Search API. In loop iterations, executes targeted follow-up queries generated by the Gap Evaluator. Enriches every retrieved source with quality metadata.

3. **Source Quality Assessment (`backend/services/source_evaluator.py`)**  
   Evaluates each source on:
   - **Domain Identity**: Government/Registry, Industry Analyst, Tech News, Corporate, or Blog.
   - **Source Type**: Primary (official filings, datasets), Secondary (analyst reports, news), Tertiary (aggregators, opinion).
   - **Relevance & Depth**: Snippet length and contextual depth.
   - **Quality != Truth Caveat**: Explicitly notes that prestige domains indicate editorial process, but specific facts still require independent empirical corroboration.

4. **Analysis Agent (`backend/agents/analyst.py`)**  
   Extracts multi-dimensional findings, binding every finding to specific source URLs.

5. **Gap Evaluator Agent (`backend/agents/evaluator.py`)**  
   Audits whether the current evidence thoroughly answers the research questions. If critical data points are missing, it proposes up to 3 targeted follow-up queries and triggers a conditional re-search loop (strictly bounded at 3 maximum iterations to prevent infinite looping).

6. **Verification Agent (`backend/agents/verifier.py`)**  
   Acts as the strict fact-checker:
   - **Verbatim Evidence Quotes**: Extracts exact quotations from source text.
   - **Epistemic Status**: Strictly marks claims as `supported`, `conflicting`, or `insufficient_evidence`.
   - **Contradiction Comparison**: Flags empirical discrepancies (e.g., differing market sizes or growth rates) and analyzes whether discrepancies stem from differing timelines, currencies, or definitions.
   - **Mathematical Quality Metrics**: Computes exact percentages from real workflow data.

7. **Report Agent (`backend/agents/reporter.py`)**  
   Compiles the final intelligence dossier with Executive Summary, Methodology, Key Findings, Detailed Analysis, Contradictions, Limitations, and Citations.

8. **PDF Report Generator (`backend/services/pdf_generator.py`)**  
   Compiles executive-grade PDFs complete with scorecards, tables, verbatim quotes, contradiction comparisons, and clickable hyperlinks.

## 📐 Mathematically Defined Quality Metrics

Every metric is calculated directly from actual workflow execution data:

- **Evidence Coverage Percentage**:
  $$\text{Evidence Coverage \%} = \text{round}\left(\frac{\text{supported\_claims}}{\text{total\_claims}} \times 100, 1\right)$$
- **Conflict Rate Percentage**:
  $$\text{Conflict Rate \%} = \text{round}\left(\frac{\text{conflicting\_claims}}{\text{total\_claims}} \times 100, 1\right)$$
- **High-Quality Sources Percentage**:
  $$\text{High Quality Sources \%} = \text{round}\left(\frac{\text{high\_quality\_sources}}{\text{total\_sources}} \times 100, 1\right)$$
- **Total Iterations**: Real count of executed autonomous research cycles (capped at 3).

## 💻 Tech Stack

- **Frontend**: Next.js 14 (App Router), TypeScript, Tailwind CSS, Lucide React
- **Backend**: Python 3.12+, FastAPI, Uvicorn, Pydantic v2
- **Orchestration**: LangGraph (`StateGraph` with conditional looping edges)
- **Web Search**: Tavily Python SDK (`tavily-python`)
- **Document Export**: ReportLab PDF Engine
- **LLM Integration**: `langchain-openai` (OpenAI GPT-4o-mini / GPT-4o, or any OpenAI-compatible provider like Groq, OpenRouter, DeepSeek, Ollama, vLLM)

## 🚀 Setup & Execution

### 1. Backend Setup

```bash
# Navigate to backend directory
cd backend

# Virtual environment is already prepared at backend/venv
# Windows (PowerShell):
.\venv\Scripts\Activate.ps1
# macOS / Linux:
source venv/bin/activate

# Install dependencies (including ReportLab)
pip install -r requirements.txt

# Start the FastAPI server
uvicorn backend.main:app --host 0.0.0.0 --port 8000 --reload
```

- **Health Endpoint**: `http://localhost:8000/api/health`
- **Swagger Documentation**: `http://localhost:8000/docs`

### 2. Frontend Setup

In a separate terminal:

```bash
cd frontend

# Install packages
npm install

# Start Next.js development server
npm run dev
```

Open `http://localhost:3000` in your browser.

## 📡 API Endpoints

### `GET /api/health`
Returns system health, readiness, and service configurations.

### `POST /api/research`
Executes the multi-agent research workflow with autonomous conditional looping.

### `POST /api/research/pdf`
Accepts the research dossier payload and returns a downloadable binary PDF with clickable hyperlinks.
